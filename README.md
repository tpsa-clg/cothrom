# `cothrom`: Irish constituency boundary redistricting using statistical physics techniques

This repository developed by [The Problem Solving Association CLG.](https://tpsa.ie/problem-solving/) is a collection of C++ and Python scripts for finding optimal Irish electoral constituencies using techniques in statistical physics.

See the [documentation](https://cothrom.readthedocs.io/) for details on using the code, our [pre-print](https://arxiv.org/abs/2606.20637) for the theory behind the methods implemented, and the [release history](https://github.com/tpsa-clg/cothrom/releases) for previous releases.
