cothrom: Constituency Optimisation Through Hamiltonian Representation Of Mandates
=================================================================================

This repository developed by `The Problem Solving Association CLG.`_ is a collection of C++ and Python scripts for finding optimal Irish electoral constituencies using techniques in statistical physics.
The name comes from the Irish word *cothrom* (pronounced CUH-hrum) meaning equal or fair, and stands for "Constituency Optimisation Through Hamiltonian Representation Of Mandates".
The algorithm used by the C++ scripts is detailed in the `pre-print`_ introducing the framework.

.. _The Problem Solving Association CLG.: https://tpsa.ie/problem-solving/
.. _pre-print: https://arxiv.org/abs/2606.20637

Check out the :doc:`usage` section for instructions on running the code, and the :doc:`reference` section for details on commands and scripts.

.. note::

    This project is under active development.
